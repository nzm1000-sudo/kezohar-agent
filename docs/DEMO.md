# הדגמה פרטית על המק

עדכון שלב 5: תוקנו החיפוש ובחירת המקורות, נוספה הבחנה בין ברכה ראשונה לאחרונה, ותפילין מקבלת כעת מקור מפורש משולחן ערוך כ״ה ט׳. [חמש ההדגמות עם נסיבות המשך](PHASE5_DEMO_2026-10-12.md). המערכת מציגה קריאת מקור שלם ואינה מאשרת אוטומטית את תחולת הדין.

פתח בדפדפן: **http://127.0.0.1:8711/**. השרת מאזין ל־loopback בלבד; לא פורסם ולא נפרס ל־NAS.

הפעלה מחדש מהמסוף:

```sh
cd ~/kezohar-agent
.venv/bin/python -B scripts/demo.py
```

עצירה: Ctrl+C במסוף שבו הופעל. אם הפורט בשימוש, ההדגמה כנראה כבר פועלת; אפשר לבחור `--port 8712` ולפתוח את הכתובת התואמת. אין הורדת מודל או שינוי הגדרות LM Studio. יש להפעיל את שרת LM Studio הקיים אם בדיקת החיבור מדווחת שאינו זמין.

כתוב שאלה, לחץ על חיפוש והשבה, ובחר פרטים בשאלות ההבהרה. המקורות שמופיעים בחיפוש אינם כולם תמיכה בתשובה: יחידות שעברו אימות מסומנות ומוצגות תחילה. „פתח טקסט מקור” קורא שוב את זהות המקור והרשאותיו. אין זיכרון שיחה אישי; הבחירות נשארות בדף הנוכחי בלבד. אין שימוש במחקר רשת או במטמון תשובה ישן. תקציב ההדגמה 45 שניות וקריאת מודל אחת לבקשה; ברירות המחדל של API הרגיל לא שונו.

בהדגמה הראשונה (לפני שלב 5), חמש שאלות המשתמש הורצו עם המודל המקומי הקיים, ללא תחליף. תוצאות מלאות, כל המקורות ומצב האימות נשמרו ב־`data/store/demo-2026-10-12/results.json` (קובץ מקומי שאינו ב־Git). ההרצה הראשונה נשמרה בנפרד ב־`initial-results.json`: נחשפו ניתוב מוטעה של יעלה ויבוא ללוח השנה ו־timeout של 4.5 שניות. ניתוב שאלת הפסיקה תוקן ונוסף בירור תפילה ושלב; timeout ההדגמה מועבר כעת לתקציב שלה. למרק נוסף בירור מצב הבישול, הטמפרטורה ושיטת החימום ללא קביעת הדין.

תוצאת חמש השאלות לאחר התיקונים: 3 הבהרות ללא הפעלת Qwen, ציטוט פקאן אחד מ״עונג שבת״ שעבר אימות תוכנה (2.000 שניות), ותשובת תפילין שנחסמה (`unsupported`, ‏9.120 שניות). אין תשובה שקיבלה אישור הלכתי אנושי. כל פלט נשאר `halachic_verified=false`. ניסיון בדפדפן לפתוח את מקור הפקאן הצליח; חזרה על אותה שאלה בדפדפן הפעילה קריאת מודל חדשה ולא מטמון.

מגבלות שימוש: עדיין יש מקורות חיפוש שאינם מתאימים מספיק למקרה; בהדגמה הראשונה בתפילין לא התקבלה תשובה מאומתת. בשלב 5 נמצא והוצג הסעיף המפורש, אך גם כעת אין אישור הלכתי אנושי. אין אימות משמעות כללי, ולא כל מקרה מכוסה בבירור נסיבות. זו הדגמה פרטית בלבד ללא זהות משתמש מאומתת. אין לשנות את המאזין ל־0.0.0.0 או לפרסם את השירות.

נוספו 10 בדיקות מבודדות לחיבור ההדגמה, דחיית Host/Origin זרים, קלט פגום, העברת timeout, ביטול מטמון ובירור נסיבות. סך הכול: **187 עברו, 0 נכשלו, T20 מדולגת**. תוצאות ההרצה: `data/store/test-runs/phase4-30zvo1xx/`. לא הורצה סדרת בנצ׳מרקים.
