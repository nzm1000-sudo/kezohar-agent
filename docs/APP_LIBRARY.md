# ייבוא ספריית האפליקציה

המקור נקרא בלבד. כל הפלט נכתב בתוך פרויקט הסוכן; אין שינוי באפליקציה, NAS או LM Studio.

```bash
PYTHONPATH=src .venv/bin/python -m kezohar.app_library \
  --app-root "$HOME/Desktop/kazzohar-harakia" \
  --output-dir data/store/app-library
```

`--pack PACK_ID` מסנכרן חבילה אחת. `--grants data/permissions.local.json` קורא אישורים מתועדים. אין לשמור מסמך פרטי או סודות ב־Git.

הייבוא קורא manifests, חבילות JSON.GZ וקטלוגי MJS שמכילים JSON מילולי. הוא אינו מריץ JavaScript. קטלוגים שומרים מחבר, שם עברי, מהדורה, כותרות פרקים, פרטי רישיון ומקור. קובצי anchors שומרים מראה מקום קנוני וקישור למקור שעליו הפירוש. שכבות מקרא ותרגום אונקלוס מיובאות בנפרד. כשאין מראה מקום קנוני, נשמר זיהוי מדויק של ספר/פרק/יחידה באפליקציה, ללא המצאת סימן או סעיף.

הרשאות נבדקות עבור `local_storage`, `search_index`, `rag_answers`. הצהרה על אישור בלבד אינה מספיקה. רישיון לא מוכר/NC/אישור מחבר ללא היקף מתועד חוסם רק את טקסט החבילה הרלוונטית. אישור חריג חייב להיות מאומת, עם הפניה לראיה ועם שלושת ההיקפים, לכל קובץ:

```json
{
  "author-permission-ong-shabbat/Oneg_Shabbat.json.gz": {
    "verified": true,
    "evidence": "הפניה לרשומת אישור שבדק בעל ההרשאות",
    "scope": {"local_storage": true, "search_index": true, "rag_answers": true}
  }
}
```

יש להשתמש בשם הקובץ המדויק מתוך manifest. אישור לחיפוש בלבד אינו מאשר RAG. רשומות רישיונות פתוחים מבוססות על מדיניות הרישוי הקיימת בפרויקט ועל הייחוס שבספרייה; זו אינה בדיקה משפטית של כל עותק. דרישות ייחוס ושיתוף זהה נשמרות במטא־נתונים ובתוצאות, לרבות קישור לרישיון וסימון החלוקה למקטעים. מקורות התנאים: [CC BY](https://creativecommons.org/licenses/by/4.0/), [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/).

פלט:

- `library.sqlite3`: מקטעים וחותמות SHA256 לקבצים, אינדקס FTS5 על עברית מנורמלת.
- `sources.jsonl`: ייצוא אטומי תואם למודל המקורות הקיים.
- `provenance.json`: manifests, קטלוגים, מסמכי ייחוס ועיגונים פעם אחת; המקטעים שומרים הפניה/חותמת ומטא־נתונים של יחידתם.
- `report.json`: עדכונים, קבצים שלא השתנו, חסימות ושגיאות, ללא העתקת טקסטים חסומים.

סנכרון מוגן בנעילת קובץ. כל עדכון קובץ הוא טרנזקציה; מזהים נגזרים מהמהדורה/יחידה/מספר מקטע ונשארים יציבים כשמילות היחידה מתעדכנות. הייבוא אינו מאחד מהדורות שונות גם כשהטקסט זהה. ביטול הרשאה/קובץ שהוסר/פגיעה בתקינות מוציאים את המקטעים מהחיפוש. FNV-1a של האפליקציה, גדלי קבצים ו־SHA256 כשסופק נבדקים. FTS מתעדכן באמצעות triggers באותה טרנזקציה. ניתן להמשיך לאחר ניתוק באמצעות הרצה חוזרת.

אימות מקומי 2026-10-11: 43 חבילות, 825 קובצי תוכן מותרים, 744,177 מקטעים, 130 קובצי תוכן חסומים (73 NC,‏ 55 NC-SA,‏ 2 אישור מחבר), אפס שגיאות. הרצה מלאה חוזרת זיהתה 825 קבצים ללא שינוי וללא תוספת מקטעים. נתוני המקור והאינדקס אינם ב־Git.

מדידה על Mac: בניית FTS ראשונית כ־15.3 שניות; שלוש שאילתות על 732,485 מקטעים כ־1.8 / 61.2 / 13.4 מילישניות. זו מדידת חיפוש מילולי מקומית, ולא ביצועי NAS או embedding סמנטי.
