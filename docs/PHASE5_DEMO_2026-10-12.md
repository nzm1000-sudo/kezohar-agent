## מה עדיין חסר

קריאת מקור אינה אימות משמעות כללי. ארבע התוצאות החיוביות הן טקסטים אמיתיים שנבחרו על ידי Qwen והוצגו בשלמותם; הן אינן ארבע פסיקות חופשיות שהמודל ניסח והמערכת הוכיחה. ניסוחים חופשיים אינם מאושרים בלי תמיכה תחומה שנבדקה. יחידת המקור שומרת את כל תנאיה, אך תנאים מחוץ למקטע, התאמת הענף לנסיבות, שיוך מדויק של ההגה והכרעה במחלוקת עדיין דורשים סקירה הלכתית. גם חלק ממועמדי החיפוש עדיין משיקים בלבד. שאלת השמן זקוקה למקור מפורש מתאים, וברכה אחרונה זקוקה למקורות ותמיכה בתנאיה, מעבר לשורת הטבלה.

אין זהות משתמש HTTP מאומתת או מוכנות לציבור. ההדגמה אינה כותבת זיכרון משתמשים או הצעות לגרף המקורות הפעיל. תיעוד פלטי המודל הופעל רק להרצות המפורשות, לתיקייה מבודדת עם הרשאות מקומיות, וכובה לפני השארת הממשק לשימוש עצמי. לא מוצגים פלטים גולמיים לא מאומתים בממשק.

בדיקות ממוקדות של החיפוש, הפרוטוקול, הרשאות משתנות, שמירת התנאים, כמות/זמן ובירור מוגבל: נוספו 20 מקרי רגרסיה. **207 עברו, 0 נכשלו, T20 מדולגת**; 0 ניסיונות I/O חיצוני בסוויטה המבודדת. שתי תקלות בבדיקות החדשות תוקנו: import חסר של fixture ומקרה unknown שלא היה ערך נתמך ל־rice_form. הבדיקה החלופית משתמשת ב־blessing_stage=unknown הנתמך. אין טענה שכל הבדיקות ההיסטוריות או עומס רב־משתמשים נבדקו.

הפעלה מחדש: `.venv/bin/python -B scripts/demo.py` מתוך הפרויקט. להרצת ההדגמה עם נסיבות ההמשך: `.venv/bin/python -B scripts/demo_phase5.py`; כל הרצה עתידית נשמרת בתיקיית run חדשה, בלי לדרוס את התוצאות המקוריות. אין צורך להתקין, להוריד או לשנות מודלים.
